## 🛠️ Technology Stack & Architecture

- **Visual Design**: Obsidian/Dark technical aesthetics (`#050505`) with warm amber accents (`#ff6f00` / `#ff9500`), subtle grid geometry, ambient canvas shaders, and 3D ribbon emblem.
- **Frontend**: Responsive semantic HTML5, modern CSS3 (Custom Properties, Grid, Flexbox, clamp typography), and modular JavaScript.

- **Backend / Server**: Lightweight Node.js server (`server.js`) with WebP/SVG support and honeypot-protected inquiry REST API.
